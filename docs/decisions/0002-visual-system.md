# 0002: Give Village a warm, mobile-first visual system

- Status: Accepted
- Date: 2026-10-02

## Context

Village is primarily for parents using their phones, but its public landing page also needs to feel credible to a desktop portfolio audience. A visual identity centered on children could make the product feel like a daycare site and overlook the parent-facing parts of Village.

## Decision

Use a warm, restrained nature-inspired palette with semantic CSS tokens, readable system typography with an editorial display face, and small reusable components organized by shared or product-domain responsibility. Compose mobile layouts first and use fictional, typed presentation data outside UI components. Keep family artwork abstract and the voice addressed to adults.

## Consequences

The interface can evolve through shared tokens and components while keeping the product welcoming, calm, and legible. The current examples communicate planned experiences only; they are not live discovery, recommendation, community, or privacy features.

See [`docs/decisions.md`](../decisions.md) for the visual architecture details.
